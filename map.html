«Чистая Гавань» — мокапы бизнес-процессов

Основной сценарий CRM: заявка → клиент → сделка → заказ → назначение исполнителя → QR объекта → выполнение по чек-листу → контроль качества → завершение → кабинет клиента. Каждый экран ниже — отдельный HTML-файл, открывается в браузере без сервера.

Основной workflow

ШАГ 0 · ВСЕ РОЛИ
Вход в CRM
JWT-логин сотрудника, возврат на исходный URL
 →
ШАГ 1 · MANAGER
Заявка
Входящий запрос: источник, клиент, объекты, обработка → выиграна / потеряна
 →
ШАГ 2 · MANAGER
Сделка
NEW → QUALIFICATION → CALCULATION → PROPOSAL → WON
 →
ШАГ 3 · OPERATOR
Заказ + назначение
Создан из WON-сделки, планирование, сотрудник/бригада
 →
ШАГ 4 · EMPLOYEE
QR на объекте
Скан publicId → заказ на сегодня → «Начать работу»
 →
ШАГ 5 · EMPLOYEE
Уборка + чек-лист
Стадии «В работе» → «Уборка», пункты «Выполнен»/«Не выполнен»
 →
ШАГ 6 · OPERATOR
Контроль качества
Принять / отклонить → завершение заказа
 →
ШАГ 7 · КЛИЕНТ
Кабинет клиента
Статус заказа, фото, документы, история уборок

Вспомогательные экраны CRM

Дашборд

Метрики по заказам, выручке, загрузке. Роли ADMIN/MANAGER/OPERATOR.

 Заказы — календарь

День/неделя/месяц/расписание, drag-and-drop перенос и resize, повторы, drawer заказа.

 Календарь

Неделя: запланированные и идущие заказы по исполнителям.

 Задачи

Список задач с фильтром «Просроченные» — переход с карточки дашборда.

 История

Единая лента HistoryEvent по всем сущностям — аудит действий.

Как смотреть

Откройте mockups/index.html в браузере — стартует экран входа, дальше переходите по ссылкам. Состояния показаны как в реальном UI: у заказа три экрана соответствуют статусам Запланирован/Назначен → В работе → На проверке.
